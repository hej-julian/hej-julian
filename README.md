# Hey, I'm Julian 👋

**IT Infrastructure · Linux & Networking · Software Development**

I build and maintain Linux-based infrastructure, self-hosted services, and web applications. I enjoy working across the stack — from servers, containers, and networking to APIs and modern user interfaces.

### 🔧 What I work on

- 🐧 **Linux & infrastructure:** Debian server administration, Docker, Docker Compose, Nginx, and Plesk
- 🌐 **Networking & security:** WireGuard, reverse proxies, authentication, and secure service deployments
- ⚡ **Backend & real-time systems:** Node.js, TypeScript, REST APIs, WebSockets, Socket.IO, and gRPC
- 🎨 **Web development:** Svelte, React, Next.js, and responsive frontends
- 🛠️ **Operations & automation:** Self-hosting, troubleshooting, version control, and maintainable production setups
